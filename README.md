# Personal Notes

A simple personal notes application built with **Laravel, PHP, and MySQL**.

This project is being developed as a learning project to understand Laravel and build a complete CRUD-based application.

## Features

* Create notes
* View notes
* Delete notes 
* Update notes *(coming soon)*
* Form validation

## Tech Stack

* Laravel
* PHP
* MySQL
* Blade
* HTML/CSS

## Getting Started

```bash
git clone https://github.com/PriyanshuRoushan/Personal-Notes.git
cd Personal-Notes
composer install
cp .env.example .env
php artisan key:generate
php artisan migrate
php artisan serve
```

Configure your MySQL database in `.env` before running the migrations.
